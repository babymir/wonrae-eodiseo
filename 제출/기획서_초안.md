## 1. 문제 정의 (30)

### 1-1. 직접 겪은 문제
- 제안서에 "이익 난 주식을 팔 **확률이 2.18배**"라고 썼다. 원 보고서(자본시장연구원 22-02, 45쪽)를 찾아보니 '확률'이 아니라 **'위험비율 2.1821배'**였다.
- 어떤 기사의 "임금 격차 **194만 원**"은 원 통계에 없었다. 기자가 두 숫자(405.2−211.2)를 빼서 만든 값이었다(국가데이터처 보도자료 22쪽).
- 기관 발표 '분양 2,103건'은 기탁기관을 합한 숫자였고, 그 기관 단독은 1,700건이었다.
- 기사에는 원문 링크가 없다. 원문을 찾아 쪽까지 확인하는 데 **숫자 하나에 30분 넘게** 걸린다. 그래서 바쁠 때는 확인 없이 그대로 옮겨 쓴다.

### 1-2. 누가, 언제
- **대상 사용자**: 보고서·제안서·기사에 남의 숫자를 인용하는 사람 — 정책·연구 실무자, 기자·편집자, 공공기관 홍보 담당, 기업 리서치·PM
- **쓰는 순간**: 숫자를 인용하기 직전("이 숫자, 원래 어디서 나왔지?")
- [페르소나 1명: 이름 없이 직무·상황·지금 하는 방법·걸리는 시간]

### 1-3. 문제의 크기(근거 2~3개 — 출처는 reports/ 조사 보고서)
- 범용 AI 검색은 원문 대신 사본·기사를 인용하고, 모르면서도 답한다: Tow Center(2025-03) AI 검색 8종 오답률 60% 이상, 지어낸·깨진 주소 다수
- 기자들은 AI를 쓰지만 사실 확인에는 잘 쓰지 않는다: 한국 기자 AI 사용 58.1%, 그중 사실 확인 23%(언론진흥재단 2025)
- 독자는 사실을 확인할 때 공식 출처로 간다(Reuters Institute DNR 2025, 35%)
- [숫자가 원문에서 기사로 옮겨지며 바뀌는 방식 분류: 기간·대상·단위·용어 바뀜, 기사가 계산, 반올림, 다른 판 인용]

## 2. 해결 방법과 완성도 (30)

### 2-1. 흐름
[흐름도 1장]
1. 입구: 확인할 통계 문장인지 가린다(의견·계획·행사 소식은 '확인 대상 아님')
2. 문장 분해(라이너 모델): 기관·보고서·숫자·핵심어·기준 시점·기관 누리집·원어 검색어
3. 원문 후보 찾기: 라이너 웹 검색(기관 누리집 안, 원어), 라이너 Scholar(논문), 공식 경로(정책브리핑 보도자료, DART 공시, 여론조사심의위 등록 결과)
4. 원문 읽기: PDF·HWP·HWPX·엑셀·웹 페이지·첨부·공시 표
5. 숫자 찾기: 표기 변환(1,784원↔1784원, 1840만 배럴↔18.4 mb/d, 억 반올림, 베이시스포인트 등) + 핵심어 확인
6. 판정(라이너 모델·Decisions): 원문 문장과 칸별 비교(지표·대상·시점·비교 기준·수준)
7. 못 찾으면: 왜 없는지(시세 화면·여론조사·공시·국가통계 원자료)와 확인할 곳 안내

### 2-2. 결과 종류(화면에서 3단으로 묶음)
| 묶음 | 판정 | 뜻 |
|---|---|---|
| 원문 확인됨 | 일치 / 표현 바뀜 / 기사가 계산 / 숫자 다름 | 원문 쪽·문장을 그대로 보여 줌 |
| 사람 확인 필요 | 표현 다름 후보 / 통계표·원자료 인용 | 같은 숫자인데 기사가 표현을 바꿈, 또는 통계표 위치 |
| 원문 못 찾음 | 원출처 미확인 / 원문에 없음 / 확인 대상 아님 | 지어내지 않고 이유와 확인할 곳을 알려 줌 |

### 2-3. 평가 방법(정직한 성적표)
- **세트 분리**: 개발 세트(보면서 고침) / 검증 세트(일반 규칙 효과만 잼) / **시험 세트(11/22 코드 동결 뒤 1회만)**
- **분모**: 사람(에이전트)이 직접 찾아 공개 원문이 있다고 확인한 문장만. 원문이 비공개인 숫자(시세·유료 자료·발언)는 따로 센다
- **채점**: 판정 이름이 아니라 **근거 문서가 정답 원문과 같은지** 대조. '사람 확인 필요'는 따로 셈
- **성적표**: [표 — 분모 / 원문 문장 확인(구간) / 넓게 센 비율 / 틀린 단정 / 건당 시간]
- **기준선 비교**: 같은 문장을 범용 AI 검색(라이너 Deep Research·검색+AI)에 넣은 결과 [표]
- **오류 분류**: 후보 단계에서 놓침 / 원문은 읽었는데 숫자 대조에서 놓침 / 조회 화면·접속 차단
- 개발 중 추이(부록): 새 무작위 40건 29% → 77%, 무작위 100건 '숫자까지 확인된 원문' 기준 원문 문장 확인 71%(95% 구간 57~82%)

### 2-4. 한계(먼저 밝힘)
- 원문이 공개 문서로 없는 숫자(시세, 유료 데이터, 관계자 발언)는 찾을 수 없다 → '확인할 곳' 안내
- 조회 화면 안의 숫자(오피넷·세이브로·KIND 등)는 아직 숫자까지 확인하지 못한다
- 자동 접속을 막은 누리집은 우회하지 않는다(검색 요약으로만 확인하고 그렇다고 표시)
