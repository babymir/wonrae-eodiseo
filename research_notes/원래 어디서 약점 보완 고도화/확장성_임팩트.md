# 「원래 어디서?」 확장성·임팩트 전략 (2026-11-12 기준 조사)

> 표기: **[확인]** = 출처로 확인한 사실, **[직접 확인]** = 이 조사에서 curl로 직접 확인(2026-11-12), **[추론]** = 출처를 바탕으로 한 판단. 조사 도구 호출 약 17회로 범위를 제한했으므로 빈 곳은 Gaps에 적었다.

## 1. 커버리지 확장: 어떤 기관을, 어떻게 넣을 것인가

### Takeaway
주요 국책연구원·공공기관 대부분은 robots.txt에서 일반 크롤러를 허용하지만, KLI(전체 차단, 검색엔진만 허용)·KIEP(주요 봇 차단)처럼 막는 곳과 KDI처럼 robots는 허용하지만 기본 User-Agent 요청엔 빈 응답을 주는 곳이 섞여 있다. 따라서 "기관별 스크레이퍼 추가"보다 **"검색(site:)으로 상세 페이지 찾기 → 상세 페이지에서 PDF 링크 일반 추출 → 실패 시 기관별 규칙"** 의 3단 구조가 확장에 유리하다.

### Cited Findings
- robots.txt 직접 확인 결과(2026-11-12) **[직접 확인]**:
  - kdi.re.kr: `User-agent: * / Allow: /` — 전체 허용. 그러나 User-Agent 없이 curl로 `/research/reportList`를 요청하면 117바이트만 돌아오고, 브라우저 UA를 붙이면 약 141KB 정상 페이지가 돌아옴 → UA 기반 차단(봇 필터). 기존에 알던 "KDI 차단"은 robots가 아니라 이 필터로 보임.
  - kcmi.re.kr: 전체 허용 / kihasa.re.kr: `/search/`만 차단 / mods.go.kr: 내부 검색엔진 경로만 차단 / krihs.re.kr(국토연): 전체 허용(Googlebot만 검색경로 차단) / kiet.re.kr(산업연): 허용하되 `/common/file/` 등 차단(파일 다운로드 경로가 막혀 있을 가능성) / kipf.re.kr(조세재정연): 일반 허용, Bytespider·Amazonbot 등 일부 AI·SEO 봇만 차단 / krivet.re.kr: 관리자 경로만 차단 / kosis.kr: 전체 허용(Googlebot만 검색경로 차단)
  - **kli.re.kr(한국노동연구원)**: `User-agent: * Disallow: /` 후 Yeti(네이버)·Googlebot·Daum만 허용 → 우리 봇의 직접 수집은 robots 위반. 검색엔진 경유(site:)로만 접근하는 것이 원칙상 맞음.
  - **kiep.go.kr(대외경제정책연)**: Yeti·Googlebot·Bingbot·Daumoa·OAI-SearchBot·Google-Extended를 `Disallow: /`로 묶고 `/board.es`, `/boardDownload.es` 등 일부만 Allow → 게시판·첨부 다운로드 경로는 명시 허용.
  - **bok.or.kr(한국은행)**: `Disallow: /` 후 `/portal/` 등만 Allow → 실제 사이트 본체가 `/portal/` 아래이므로 보도자료 등은 허용 범위로 보임(경로 확인 필요).
  - korea.kr(정책브리핑): 전체 허용 + `Sitemap: https://www.korea.kr/sitemapindex.xml` 제공 → 부처 보도자료는 사이트맵 기반 수집이 가장 쉬움.
  - nkis.re.kr: robots.txt 요청 시 에러 페이지 반환(robots 없음).
- 한국은행 ECOS Open API: 무료 인증키, 금리·환율·물가 등 4,000개 이상 시계열 — [data.go.kr ECOS](https://www.data.go.kr/data/15059632/openapi.do), [R ecos 패키지 README](https://search.r-project.org/CRAN/packages/ecos/readme/README.html), [블로그(제3자)](https://bcuts.tistory.com/293). 하루 약 1,000회 제한은 제3자(Apify) 기재로 미검증 — [Apify](https://apify.com/nexgendata/korea-bok-monetary-policy-ecos)
- NKIS: 경제·인문사회연구회 소관 연구기관 성과를 모은 포털이며 인증키 기반 Open API 제공 — [koreascience 논문](https://koreascience.kr/article/JAKO202111268730685.page?lang=ko). 2021년 논문 기준 API는 "아주 간단한 수준의 기본 서지 정보"이고 원문은 NKIS로 이동해야 확인 — [koreascience PDF](https://koreascience.kr/article/JAKO202111268730685.pdf) (현행 사양은 미확인)
- 정책브리핑 보도자료 첨부 전용 공공 API는 찾지 못함. 가장 가까운 것은 KTV 게시글 조회 API(보도자료 게시판·첨부파일 항목 포함, 무료) — [data.go.kr](https://www.data.go.kr/data/15136860/openapi.do)
- KDI는 2004년부터 네이버 디렉토리에 보고서를 등록해 검색 노출 — [KDI 공지](https://www.kdi.re.kr/share/noticeView?bd_no=5346). 일부 발간물은 유료 판매 정책 — [KDI 판매정책](https://www.kdi.re.kr/share/noticeView?bd_no=4883)
- robots.txt는 강제력이 없는 자율 규칙 — [Google 검색센터](https://developers.google.com/search/docs/advanced/robots/intro?hl=ko)

### 법·이용조건 (공공누리, 저작권)
- 공공누리 제1유형: 출처표시 시 상업적·비상업적 이용과 2차적 저작물 작성 모두 가능 — [문체부 공공누리 유형](https://www.mcst.go.kr/site/s_open/kogl/koglType.jsp)

- 자동 수집(크롤링) 자체를 허용·금지하는 공공누리 공식 지침은 찾지 못함. KDI는 홈페이지 자료 무단 사용을 금지하고 타 사이트 소개 시 문의를 요청 — [KDI FAQ](https://kdi.re.kr/res/file/faq.pdf)

### Inferences
- **[추론]** 우리 서비스는 PDF를 "재배포"하지 않고 **원문 링크 + 짧은 인용 + 쪽 번호**만 보여 주면 공공누리 1~4유형 어느 것이든(변경금지 유형 포함) 위험이 낮다. 결과 화면에 기관명·보고서명·연도·URL을 자동 표기하면 1유형 출처표시 요건과 그대로 맞물린다.
- **[추론]** 확장 우선순위(뉴스 인용 빈도 × 접근성): ① 정책브리핑(korea.kr, 사이트맵으로 전 부처 보도자료 일괄) ② 한국은행(ECOS API로 수치값 직접 대조 가능 → KOSIS 외 "값 검증"을 처음 추가할 수 있는 곳) ③ NKIS(26개 연구원 서지를 한 번에, 원문은 각 기관 상세 페이지) ④ KDI·조세재정연·노동연 등 개별 기관.
- **[추론]** 기관 무관(institution-agnostic) 방식: (a) Liner site: 검색으로 상세 페이지 URL 확보 → (b) 상세 HTML에서 `.pdf`, `download`, `fileDown`, `boardDownload.es` 등 패턴과 "원문/첨부/다운로드" 글자 근처 링크를 점수화해 PDF 후보 추출 → (c) 내려받은 파일의 Content-Type·첫 바이트(`%PDF`)·제목 유사도로 검증 → (d) 실패한 기관만 규칙 파일(YAML)에 추가. 이러면 "기관 추가 = 코드 수정"이 아니라 "설정 한 줄"이 된다.
- **[추론]** robots에서 일반 봇을 막은 KLI·KIEP는 직접 수집 대신 "검색 결과 링크 제시 + 사용자가 열어 확인" 모드로 처리하는 것이 안전하다. KDI는 robots상 허용이므로 브라우저 UA·저속 요청으로 가능하지만, 명시적 식별(봇 이름+연락 페이지) UA를 쓰는 편이 투명성 측면에서 낫다.

### Gaps
- 국책연구원 26곳 전체의 PDF URL 패턴·robots 목록은 대표 기관만 확인했다(나머지 미조사).
- 뉴스가 "어느 기관 수치를 가장 많이 인용하는지"에 대한 정량 자료(빅카인즈 기준 기관명 언급 빈도 등)는 찾지 못했다. 빅카인즈로 직접 집계하면 확장 우선순위의 근거가 된다.
- NKIS Open API의 현행 응답 항목(원문 URL 포함 여부), 지자체 통계(각 시도 통계 포털) 접근성은 미확인.

## 2. 임팩트 근거: 통계 오인용은 얼마나 자주, 얼마나 비싼가

### Takeaway
"한국 기사 중 통계 오인용 비율"을 직접 잰 최신 연구는 찾지 못했다. 대신 쓸 수 있는 근거는 ① KOSIS 팩트체크 게시판 116건(2026-11 기준, 최근 10건 모두 국가데이터처) ② 2004~2010년 통계청 해명 129건 분석 논문 ③ 언론중재위 연간 조정사건 약 4천 건 ④ 영국 통계규제청(OSR) 사건의 40%가 통계 오용 ⑤ 대통령 지적 → 정부 AI 오보검증 예산 7억여 원이라는 "정책 수요" 신호다.

### Cited Findings
- KOSIS 팩트체크 게시판: 총 116건(12쪽). 최근 10건(2026-08-07~2026-11-02)은 매일경제·조선일보·이데일리·문화일보·한겨레·아이뉴스24·연합뉴스·조선비즈·파이낸셜뉴스 등 보수·진보·경제지 가리지 않고 분포, 관련기관은 모두 국가데이터처. 예: "고용동향의 청년층 연령 기준은 변경된 것이 아닙니다"(문화일보, 2026-10-16), "주택소유통계의 '비거주 주택 수'에는 1주택과 2주택이상이 모두 포함"(파이낸셜뉴스, 2026-08-13) — [KOSIS 팩트체크](https://kosis.kr/serviceInfo/factCheckList.do)
  - 주의: 검색 스니펫에는 "총 106건"으로 나온 시점도 있어, 2026년 5월~11월 사이 약 10건이 추가된 것으로 보임(같은 출처의 시점 차이).
- 「국가통계의 언론보도 사례 분석」(KCI): 통계청이 2004-01~2010-02 언론 보도에 해명한 129건 분석. 실업률 등 경제 분야가 가장 많고, 같은 논쟁 반복·감정적 표현·기자의 통계적 사고 부족을 지적 — [교보 스콜라](https://scholar.kyobobook.co.kr/article/detail/4010027871808)
- 1999년 「언론보도사례를 통해 본 통계발표상의 문제」: 공식·사회조사 통계가 언론에 전달되는 과정의 문제 — [koreascience](https://www.koreascience.or.kr/article/JAKO199911920781641.page)
- 언론중재위원회: 2025년 조정사건 4,026건 접수·처리 — [뉴데일리](https://www.newdaily.co.kr/site/data/html/2025/12/26/2025122600126.amp.html) 계열 보도 / 2024년 3,937건 — [기자협회보](https://www.journalist.or.kr/ezview/article_main.html?no=58948). (정정보도 청구만의 건수, 통계 관련 비중은 미확인)
- 국가데이터처 AI 오보 검증: 조선일보 2026-10-29 "'엉터리 기사' 李대통령 지적에…'AI 오보 검증' 예산 7억여원 배정". 국가데이터처 설명자료: 기사 속 통계를 공식 통계와 비교하는 과정 자동화, 대상은 "공식 통계로 확인 가능한 수치와 통계 속성 오류"로 한정, 맥락 분석은 기준 시점·모집단·단위·지표 정의 대조, 오류 시 정정 협조 요청에 그치고 수정 여부는 언론사 판단, "언론 위축 장치가 아니다" — [정책브리핑 설명자료](https://m.korea.kr/briefing/actuallyView.do?newsId=148974587). 2027~2028년 구축 일정은 2026-07-15 업무보고 — [뉴시스](https://www.newsis.com/view/NISX20260715_0003709549)
- 영국 OSR 2025/26 사건 검토: 167건 조사(전년 219건), 그중 "통계 이용/오용"이 40%(전년 32%). 제기 주체는 일반 시민 약 50%, 하원의원 6%, OSR 자체 모니터링 25%(전년 12%). 평균 처리 30일, 중앙값 22일 — [OSR Annual review of casework 2025/26](https://osr.statisticsauthority.gov.uk/publications/annual-review-of-casework-2025-26/pages/3/)
- 언론진흥재단 '2026 해외 미디어 동향' 2호(2026-08-04): 전 세계 팩트체크 기관 76%가 재정 위기, 국내 기자 58.1%가 생성형 AI 활용, 기자가 매긴 생성형 AI 정확도 2.74점 — [뉴스1](https://www.news1.kr/amp/life-culture/general-cultural/6249304). 생성형 AI 활용 기자 중 23.0%가 사실 확인·검증에 사용(2025 언론인 조사) — 검색 요약 기준, 원문 미확인
- 정정보도 비교 연구(2007): 한국 일간지 평균 기사 오류 수가 미국 일간지의 절반 수준(정정 '보도' 기준이라 과소 집계 가능) — [한국언론정보학보](https://koreascience.or.kr/article/JAKO200705812533765.page)

### Inferences
- **[추론]** 발표용 핵심 문장 후보: "정부가 공식적으로 '이 기사는 통계를 잘못 썼다'고 밝힌 것만 116건 — 그런데 이것은 국가데이터처 통계에 한정된 빙산의 일각이다. 국책연구원 보고서 인용은 아무도 공식 점검하지 않는다." (KOSIS 게시판 최근 건이 모두 국가데이터처라는 사실이 근거)
- **[추론]** 오류 유형이 "정의·범위(청년 연령 15~29 vs 15~34, 비거주 주택 수 포함 범위)" 중심이라는 점은 우리 서비스의 '의미 변화 판정'(숫자는 맞지만 뜻이 바뀜)이 정확히 겨냥하는 영역이다. 정부 시스템은 "값 대조" 중심, 우리는 "원문 맥락 대조"로 차별화.
- **[추론]** 시간 절감은 실측해야 한다. 데모에서 "기자가 원문 PDF를 찾아 해당 쪽을 확인하는 데 걸린 시간(수작업) vs 서비스 결과 시간"을 5~10건 직접 재서 보여 주는 것이 문헌 수치보다 설득력이 높다.

### Gaps
- 한국 기사 전체 중 통계 오인용 비율을 측정한 2020년대 연구는 찾지 못함.
- 언론중재위 정정보도 청구 중 "통계·수치" 관련 비중, 통계 오보의 경제적 비용(금액) 추정치는 찾지 못함.
- KOSIS 팩트체크 116건 전체의 기관별·유형별 분포(2~12쪽)는 미집계 — 직접 크롤링해 분류하면 좋은 근거 자료가 된다.

## 3. 사업·도입 경로

### Takeaway
국가데이터처 시스템은 2027~28년 구축, "공식 통계 값 대조 + 정부→언론 정정 요청" 구조라 **연구보고서 원문·발행 전 점검·언론 스스로 쓰는 도구**는 비어 있다. 팩트체크 업계는 재정이 약하므로(76% 재정 위기) 언론사 직접 판매보다 **기관(재단·연구원·공공기관) 예산 + 플랫폼 파트너(Liner)** 쪽이 현실적이다.

### Cited Findings
- 국내 팩트체크 생태계: SNU팩트체크는 네이버 지원 중단 1년 만에 무기한 운영 중단, 읽기 전용 유지 — [기자협회보](https://www.journalist.or.kr/m/m_article.html?no=56539). 다만 2026년 6월 IFCN과 SNU팩트체크가 서울에서 '글로벌 팩트10' 공동 주최(75개국 550여 명) 보도도 있어 상태 확인 필요 — [다음/기자협회보 계열](https://v.daum.net/v/20260722182253475)
- 32개 매체 팩트체커들이 네이버 뉴스홈 '팩트체크' 존속 요구 — [기자협회보](https://www.journalist.or.kr/m/m_article.html?no=54382)
- 세명대 저널리즘대학원 2026 하반기 기후위기 팩트체크 지원사업 5개 매체 선정 — [기자협회보](https://journalist.or.kr/m/m_article.html?no=61960)
- 2026-07 정부가 사실확인 단체를 양성·지원하는 시행령이 정보통신망법 관련 우려를 키운다는 보도(본문 미확인) — [다음](https://v.daum.net/v/20260716091347819)
- 언론진흥재단 2026 미디어 스타트업 지원사업: AI·뉴스빅데이터 활용 신규 서비스, 1사당 3천만원(2026-03~04 접수, 마감) — [thevc 공고](https://thevc.kr/grants/96c80b6f6a111e9afc3c8848). 재단 주최 'AI 시대 뉴스의 가치와 팩트체크의 진화' 세미나 — [기자협회보](https://www.journalist.or.kr/news/article.html?no=61462)
- Full Fact(영국)의 AI 도구: 30개국 40개 이상 팩트체크 기관이 매일 사용(자사 주장) — [Full Fact AI](https://fullfact.org/ai/). 연차보고서 2025에선 "14개국 29개 기관"으로 수치가 다름 — [Full Fact Annual Review 2025](https://fullfact.org/documents/414/Full_Fact_Annual_Review_2025.pdf). 아랍 팩트체크 네트워크 파일럿: 응답자 15명 중 13명이 "작업이 크게 빨라졌다", 4개월간 145건 이상 발행 — [Full Fact](https://fullfact.org/world/arab-fact-checking-lessons-from-partners-in-middle-east/)
- Liner: 개발자용 Model/Router API 공개(liner-mark-1.3, OpenAI·Anthropic SDK 호환), 기업·대학 고객용 보안 체계 언급 — [Liner Model](https://liner.com/developers/liner-model), [Router API 문서](https://liner.com/developers/docs/router-api). 검색 API·B2B 요금은 미확인.

### Inferences
- **[추론] 도입 경로별 판단**
  - 국가데이터처: 경쟁이 아니라 **보완** 포지션. 저쪽은 KOSIS 값 대조, 우리는 "KOSIS 밖 원문(연구원 PDF·보도자료) + 의미 변화". 2027 시스템 구축 시 "비KOSIS 인용 처리 모듈"로 제안 가능. 단, 정부 시스템에 들어가면 '언론 감시' 논란(설명자료에서 이미 해명)을 함께 떠안는다.
  - 언론사(연합뉴스·방송사 팩트체크팀): 발행 전 데스크 점검용(브라우저 확장/CMS 플러그인)이 맞다. 사후 지적형은 언론사가 돈을 낼 이유가 약하다.
  - 공공기관·국책연구원 홍보팀: "우리 보고서가 기사에서 어떻게 인용되는지" 모니터링 → 오인용 시 설명자료 작성 지원. KOSIS 게시판 116건이 바로 이 업무의 수작업 결과물이므로 수요가 실재한다. 가장 지불 의사가 높을 후보.
  - 국회·정당 보좌진: 질의서·보도자료 수치 출처 확인(발행 전 점검). 영국 OSR 사례처럼 정치인 발언 통계가 주요 오용 대상.
  - 컨설팅·리서치·교육: "내 문서 숫자 출처 찾기"로 Liner 기존 사용자층(학생·연구자)과 맞음.
  - Liner: 우리 에이전트를 Liner 검색 위의 "출처 검증 모드"로 붙이는 B2B2C가 가장 빠른 확산 경로.
- **[추론]** 언론진흥재단 미디어 스타트업 지원(3천만원), 뉴스빅데이터(빅카인즈) 연계가 초기 자금·데이터 경로로 현실적.

### Gaps
- 국내 언론사 팩트체크팀 규모·예산, 공공기관 언론 모니터링 시장 규모는 찾지 못함.
- Liner의 기업용 검색 API 제공 여부·가격은 공개 자료로 확인되지 않음.
- 국가데이터처 시스템이 KOSIS 외 출처를 포함할지, 외부 협력(위탁)을 계획하는지는 설명자료에 없음.

## 4. 해외·다국어 확장과 "내 문서 숫자 점검"

### Takeaway
영국은 통계규제청(OSR)이 통계 오용을 공식 사건으로 다루고(2025/26 167건 중 40%), Full Fact가 AI 도구를 30여 개국에 보급하는 등 "통계 출처 검증" 수요와 제도가 이미 있다. 같은 구조(공식 통계청 + 국책 싱크탱크 PDF + 언론)는 영국·일본 등에서 재현 가능하지만, 언어별 숫자 표기·검색 연동은 새로 만들어야 한다.

### Cited Findings
- OSR: 사건 제기의 25%가 자체 모니터링(전년 12%에서 두 배) → 규제기관 스스로 모니터링 자동화 수요 증가 — [OSR](https://osr.statisticsauthority.gov.uk/publications/annual-review-of-casework-2025-26/pages/3/)
- OSR은 2026년 선거 기간 대응을 검토해 정치 논쟁 속 오용에 더 빨리 대응할 계획 — [OSR casework themes](https://osr.statisticsauthority.gov.uk/publication/annual-review-of-casework-2025-26/pages/4/)
- Full Fact AI는 3개 언어로 운영 — [Full Fact AI](https://fullfact.org/ai/)

### Inferences
- **[추론]** 해외보다 먼저 **"내 문서 숫자 점검(발행 전)"** 확장이 효과가 크다: 같은 엔진(수치 추출 → 원문 검색 → 의미 대조)을 그대로 쓰고, 사용자가 자기 원고를 올리므로 명예훼손·오탐 위험이 거의 없으며, 공공기관 보도자료 검수·보좌진·학생 리포트까지 수요가 넓다.
- **[추론]** 해외 확장 순서: 영어권(영국 ONS·IFS 등) → 일본. 영국은 OSR·Full Fact가 있어 파트너/비교 대상이 명확. 일본어는 숫자 단위(万·億) 처리가 한국어(만·억)와 비슷해 수치 정규화 로직 재사용 여지가 큼.

### Gaps
- 일본·대만 등 아시아 통계청의 언론 오용 대응 제도, 영국 외 국가의 통계 오용 공식 통계는 조사하지 못함.
- 해외 유사 서비스(ClaimBuster, Factiverse 등)의 "원문 PDF 추적" 기능 유무는 미조사.

## 5. 위험과 대응

### Takeaway
가장 큰 위험은 **오탐(맞는 기사를 틀렸다고 판정)으로 기자·언론사 평판을 해치는 것**이다. 정부조차 "정정 협조 요청에 그치고 판단은 언론사가"라고 선을 그었으므로, 우리도 "판정"이 아니라 "원문 대조 근거 제시 + 사람 확인" 구조로 가야 한다.

### Cited Findings
- 국가데이터처는 자기 시스템을 "언론 보도 위축 장치가 아니다"라고 해명해야 했고, 오류 시 정정 협조 요청만 하고 수정 여부는 언론사 판단 — [정책브리핑 설명자료](https://m.korea.kr/briefing/actuallyView.do?newsId=148974587)
- 언론중재위 2025년 조정사건 4,026건, 공직자·정치인이 언론소송 최다 제기 — [기자협회보](https://journalist.or.kr/news/article.html?no=61775)
- 정부의 사실확인 단체 지원 시행령에 대한 표현 위축 우려 — [다음](https://v.daum.net/v/20260716091347819)
- 기자들은 생성형 AI 정확도를 2.74점(5점 척도 추정)으로 낮게 평가 — [뉴스1](https://www.news1.kr/amp/life-culture/general-cultural/6249304)
- KOSIS 팩트체크 사례 다수가 "기준 변경 아님" "범위 포함 설명" 등 해석·정의 문제 — [KOSIS 팩트체크](https://kosis.kr/serviceInfo/factCheckList.do)

### Inferences
- **[추론] 대응책**
  - 판정 문구를 "오보"가 아니라 "원문과 다름 / 원문에서 확인 안 됨 / 일치"로, 그리고 확신도와 원문 쪽 번호·인용 문장을 항상 함께 표시.
  - "원문을 찾지 못함"을 "틀림"으로 처리하지 않는다(커버리지 밖 기관이 많으므로 가장 흔한 오탐 원인).
  - 공개 랭킹·언론사별 오보율 공개는 하지 않는다(평판·법적 위험). 개별 사용자 화면 결과로만 제공.
  - 데이터 최신성: 통계는 개정·잠정치 갱신이 잦다(예: 청년 연령 기준 추가 공표). 원문 발행일·기사 날짜를 비교해 "기사 이후 개정됨"을 별도 표시.
  - 이용약관에 "참고용, 최종 판단은 사용자" 명시, 근거 링크 필수 노출로 공공누리 출처표시 요건도 동시 충족.
  - 평가셋: KOSIS 팩트체크 116건을 정답 사례(정부가 오용이라 밝힌 것)로 써서 재현율을 재고, 정정 없는 일반 기사 표본으로 오탐률을 따로 잰다.

### Gaps
- 국내에서 AI 팩트체크 결과로 명예훼손 분쟁이 생긴 판례·사례는 찾지 못함.
- 국가데이터처 시스템의 목표 정확도·오탐 기준은 공개 자료에 없음.
