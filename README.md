# 원래 어디서?

**기사 속 숫자를 넣으면, 그 숫자를 처음 낸 원문(보고서 PDF 쪽, 보도자료, 공시, 통계표, 논문)을 찾아 원문 문장을 그대로 보여 주고, 기사가 원문을 어떻게 옮겼는지 알려 주는 AI 에이전트입니다.**

라이너 .EXE-THON 2026 출품작입니다. 라이너 Search·Scholar·Rerank·Model·Gateway·Decisions API를 단계마다 나눠 씁니다.

> 예) "쏘카는 3분기 연결 기준 매출 1352억원…" → DART 분기보고서 손익계산서 `영업수익(매출액) | 제16기 3분기 3개월: 135,195,115,866원` → **일치**
> 예) "걸프 지역의 석유 공급량은 하루 1840만배럴" → IEA 11월 석유시장 보고서 "Gulf oil exports … reached 18.4 mb/d" → **같은 숫자, 표현 다름(공급량 ↔ exports)**

## 무엇을 해 주나

| 결과 묶음 | 판정 | 뜻 |
|---|---|---|
| 원문 확인됨 | 일치 · 표현 바뀜 · 기사가 계산 · 숫자 다름 | 원문 쪽·문장을 그대로 보여 줍니다 |
| 사람 확인 필요 | 표현 다름 후보 · 통계표·원자료 인용 | 같은 숫자인데 기사가 표현을 바꿨거나, 통계표 위치를 알려 줍니다 |
| 원문 못 찾음 | 원출처 미확인 · 원문에 없음 · 확인 대상 아님 | 지어내지 않고, 이유와 확인할 곳을 알려 줍니다 |

- 원문을 확인하지 못한 문서로 "원문에 없음"이라고 단정하지 않습니다(기사가 틀렸다는 뜻으로 읽히기 때문).
- 한 건은 최대 60초 안에 답합니다(넘으면 그때까지 찾은 후보를 보여 줌).
- 자동 접속을 막은 누리집은 우회하지 않습니다.

## 어떻게 찾나

1. **입구**: 확인할 통계 문장인지 가립니다(의견·계획·행사 소식 제외) — 라이너 Decisions
2. **문장 분해**: 기관·보고서·숫자·핵심어·기준 시점·기관 누리집·원어 검색어 — 라이너 Model
3. **원문 후보**: 기관 누리집 안 검색, 종류가 다른 짧은 검색어, 원어 검색, 논문 — 라이너 Search·Scholar
   공식 경로: 정책브리핑 보도자료, DART 공시(OpenDART), 중앙선거여론조사심의위 등록 결과
4. **후보 순위**: 제목 + 검색 요약 — 라이너 Rerank
5. **원문 읽기**: PDF·HWP·HWPX·엑셀·웹 페이지·첨부·공시 표(행·열 이름을 붙여 한 줄로) — 글자로 안 읽히는 PDF는 라이너 Gateway
6. **숫자 찾기**: 표기 변환(1,784원↔1784원, 1840만 배럴↔18.4 mb/d, 억 반올림, 베이시스포인트, 億·万 …) + 핵심어 확인
7. **판정**: 원문 문장과 지표·대상·시점·비교 기준·수준을 칸별로 비교 — 라이너 Model + Decisions(교차 확인)
8. **못 찾으면**: 같은 숫자를 다룬 다른 기사에서 출처 이름을 얻어 한 번 더 찾고(2라운드), 그래도 없으면 확인할 곳 안내

## 실행

필요한 것: Python 3.11 이상, `curl`, `pdftotext`(poppler). 선택: `pip install pymupdf openpyxl pyhwp`(원문 쪽 그림·엑셀·HWP 첨부).

```bash
# 1) 키 넣기(이 파일은 저장소에 올리지 않습니다)
cp .env.example .env      # LINER_API_KEY, DART_API_KEY(선택, opendart.fss.or.kr 무료 발급)

# 2) 화면
python3 도구/웹서버.py    # 브라우저에서 http://127.0.0.1:8765

# 3) 명령줄로 한 문장
python3 도구/원문찾기.py "쏘카는 3분기 연결 기준 매출 1352억원, 영업이익 98억원을 기록했다고 13일 밝혔다."

# 4) 숫자 표기 테스트(API 없이 몇 초)
python3 도구/테스트_숫자표기.py
```

설정(환경 변수):
- `ORIGIN_TIME_LIMIT` 한 건 시간 상한(초, 기본 150). 시연 때는 `ORIGIN_TIME_LIMIT=60 python3 도구/웹서버.py` 처럼 줄인다(넘으면 그때까지 찾은 후보·확인할 곳을 보여 줌).
- `ORIGIN_DEEP_RESEARCH=0` 라이너 Deep Research 후보 끄기, `ORIGIN_DEEP_RESEARCH_PREFETCH=0` 처음부터 동시에 묻지 않기(비용 절약).

## 성적을 어떻게 쟀나

- **세트를 나눴습니다**: 개발 세트(보면서 고침) / 검증 세트(처음 보는 기사 30건) / **시험 세트(코드 동결 뒤 한 번만 측정)**
- **분모**: 원문을 사람(에이전트)이 직접 찾아 공개 원문이 있다고 확인한 문장만. 시세·유료 자료·발언처럼 원문이 공개되지 않은 숫자는 따로 셉니다.
- **채점**: 판정 이름이 아니라 근거 문서가 정답 원문과 같은지 대조합니다(`도구/정답대조.py`).

| 세트 | 공개 원문이 있는 문장 | 원문 문장까지 확인 |
|---|---|---|
| 시험 세트(동결 후) | [ ] | [ ] |
| 검증 세트(처음 보는 30건, 11/15) | 9 | 5 (56%, 95% 구간 27~81%) |
| 개발 세트(무작위 100건) | 45 | 32 (71%, 95% 구간 57~82%) |

```bash
python3 도구/평가_실행.py 작업/평가_검증세트          # 측정(라이너 API 사용)
python3 도구/정답대조.py 작업/평가_검증세트 --표=작업/평가_검증세트/채점표.md
```
