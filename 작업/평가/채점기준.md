# 채점 기준 (2026-11-13 고정)

사람 확인 칸은 아래 기준으로만 매긴다. 출력을 보면서 기준을 바꾸지 않는다(바꿀 때는 날짜와 이유를 아래 '바꾼 기록'에 남긴다).

## 정답으로 치는 것 (✅)
| 표시 | 언제 |
|---|---|
| ✅ 맞음 | 기사 숫자가 실린 원 보고서·보도자료의 **그 쪽**을 짚었고(표 줄 포함), 판정이 원문과 맞음. 같은 숫자가 요약문과 표 양쪽에 있으면 어느 쪽이든 인정 |
| ✅ 맞음(기사가 계산) | 기사 숫자가 원문에 없고, 원문 재료 숫자 두 개로 계산한 값이며 재료 쪽을 짚음 |
| ✅ 분류 맞음 | 기사가 KOSIS 통계표·마이크로데이터를 직접 인용했고 '통계표·원자료 인용'으로 분류함 |
| ✅ 정직한 미확인 | 지원 밖 기관·학술지·의원실 자료·공청회 자료처럼 공개 원문이 없거나 범위 밖이고, '원출처 미확인/확인 대상 아님'으로 답함 |

## 틀린 것 (❌)
- 맞는 원문이 있는데 다른 보고서·다른 달 판을 고름
- 맞는 원문을 골랐는데 숫자를 못 찾음
- 쪽은 맞는데 판정이 틀림(예: 같은 뜻인데 '표현 바뀜')
- 원 자료가 범위 밖인데 '원문에 없음'으로 답함(기사가 틀렸다는 인상)

## 판단 불가 (➖) — 분모에서 뺌
- 문장이 통계가 아님(정책 제안·발언·행정 소식·연구자 수 등) — 단, 이번 버전부터 시스템이 '확인 대상 아님'으로 답하면 ✅ 정직한 미확인으로 셈
- 문장이 잘려 무엇을 말하는지 알 수 없음
- 문장에 출처가 없고 문맥으로도 기관을 알 수 없음
